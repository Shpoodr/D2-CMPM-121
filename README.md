# CMPM 121 D2 Project

There have been a lot of changes. There are thickness buttosn that change the color of what the user will use at random. All of this has been implemented using a command like structure. You can also use stickers and if the ones that are readily availabe arent to the user's liking they can add whatever emojis they want using the add emoji button. On top of this there are undo and redo commands that work with all of the additions that have been made. Finally there is an export button for the user when they are finished with their random drawing.
